# 高级分析工作区

「观测 → 高级分析」提供三个独立页面，保留完整 usage 与流控语义；支持新 Core 时使用精确分析接口：

| 页面 | 前端路由 | 数据与操作边界 |
| --- | --- | --- |
| 可观测看板 | `/analytics/observability` | 历史请求延迟、缓存与错误；不依赖 Flow 能力 |
| 流控看板 | `/analytics/flow` | 当前受控调用、排队、观察会话趋势与运行策略检查；不读取或写入 YAML |
| 流控配置 | `/analytics/flow/config` | 独立草稿、规则、队列与观察设置；差异确认后保存 |

`/analytics` 默认进入可观测看板。旧 `/flow-control` 和 `/config?section=flow-control` 重定向到流控配置。两个流控子页沿用 Core 能力门控；能力不存在时不隐藏可观测看板。新路由纳入连接页面恢复名单。

## 用量与分析边界

`/usage` 保留请求、Token、费用、健康状态、模型占比、API/模型/凭据明细、请求事件、定价及完整导入导出。四张性能与可靠性图表移到可观测看板；用量页保留携带时间范围的入口，不重复加载分析明细。

可观测页首次直接打开默认最近 24 小时，URL 时间范围优先。进入请求事件时把当前可见相对窗口固定成绝对起止时间。自定义范围无效时不查询明细。

不支持 analytics_version: 1 的旧查询模式下，不超过 7 天自动逐页加载，超过 7 天或全部范围手动触发。四张图共用一份明细。页面分别展示尚未加载、加载中、完整结果、部分失败、用户停止和确实无请求；有样本但指标缺少有效测量时不假装为零。部分结果必须带提示，不把分页前缀当成随机抽样或全窗口最终统计。重新加载从第一页开始，避免拼接不一致快照。

可观测页仅增加模型与来源 / 凭据两个维度，四张图共用筛选后的样本。筛选选项由当前时间窗口的查询元数据提供，不从已加载分页推断；旧 Core 模式使用同一窗口的完整 usage 明细。查询模式先读取有界选项，再将模型与原始来源身份条件下推。已选来源在新窗口不存在时显示空结果，不回退到全部请求。

进入请求事件时通过导航状态携带模型与规范化来源身份，不把原始凭据或调用 Key 写入 URL。该次下钻不继承请求事件此前保存的其他条件；浏览器返回保留看板条件。清除筛选保留时间范围，旧查询模式超过 7 天仍需手动加载明细。

离开页面或更换连接、窗口、筛选、查询快照会中止旧请求。分析不增加后台轮询或持久化请求明细。

## 聚合与缓存

Core 能力 `analytics_version: 1` 启用 `POST /usage/query/analytics`，返回四图统一聚合模型与小时/天趋势，不遍历下载请求明细。首次无来源条件时只需一个聚合请求；冷启动已选来源但身份目录未缓存时，先进行一次 limit=1 的 options 查询，随后精确下推原始身份。网络、解析、5xx、容量错误不触发明细回退；未声明兼容能力的 Core 才使用旧链路。

Panel 仅在当前连接运行区内存缓存完整结果，最多 8 项 / 8 MiB、4 分钟，切换认证身份或登出清理。多个消费者共享请求，全部退出才中止。相同条件更新期间保留有时间标识的上次完整结果，换模型/来源/时间选项不借用其他条件的图表；不新增轮询或持久化明细。

请求事件下钻同时携带已显示的 bound 与参考时刻，保证明细和图表属于同一快照；事件页主动刷新才解除旧快照。Core 重启后的失效快照需显式刷新，不能静默拼接新旧结果。容量错误提示缩小时间/筛选范围；无效时间戳记录数单独提示。

跨语言对账夹具位于 Panel `src/utils/usage/fixtures/analytics-v1.json` 和 Core `internal/usage/testdata/analytics-v1.json`，覆盖时间边界、显式零测量、空值、成功/失败、缓存与 DST。

## 流控边界

看板复用 `useFlowControlStatus`、`LiveMonitor` 和运行策略模式的 `RuleInspector`。预览仍是手动有界读取，不预留许可；实际规则与本阶段容量由 Core 解释。趋势只包含本次观察的最近数据，不是历史监控。关闭流控后的新调用不计入受控摘要，因此不能标为全站并发。

配置页不挂载实时观察。查看未保存草稿、已保存期望配置、Core 已应用开关；保存仅合并 Flow 脏字段至最新 YAML，保留其他字段与注释，确认期间基线变化时重新生成差异。保存后重新读取状态，文件保存成功不等于运行策略生效。离开配置页仍受未保存保护。

## 验证

- `npm run validate:lts`：单元测试、契约、类型、lint 与构建。
- 浏览器检查三页导航、旧入口、时间窗口、明细取消、Flow 实时启停、配置保存保护、主题与移动端。
- Mock 与临时真实 Core 检查分别记录，不把构建或 Mock 通过当成生产部署验收。
