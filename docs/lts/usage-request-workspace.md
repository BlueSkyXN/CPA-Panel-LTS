# Usage 请求明细工作区与价格 smoke 修复

基于 2026-09-07 的 Core / Panel 源码包。本次不改变 Core 的用量采集、时间字段、导入导出协议或 Flow 生命周期。

## 页面

- `/usage` 保留总览、趋势、分组统计、费用摘要和导入导出。请求表默认不挂载；可选择“在此展开明细”或进入独立工作区。
- `/usage/events` 复用原请求明细组件、Usage store 与价格 profile。总览跳转携带时间范围；直接访问时继承总览保存的时间范围。自定义范围无效时不展示全部历史数据作为替代。
- `/usage/pricing` 保留现有独立价格工作台，不创建重复价格页。

请求表表头固定于表格滚动区顶部，独立页使用更大的表格高度。每页显示 100 条，可以翻到原先 500 条之后的记录。筛选或数据快照变化时返回第一页。性能摘要与 CSV/JSON 导出仍使用全部筛选结果，而不是当前页。

这是前端按需挂载和分页，不是服务端分页。`/v0/management/usage` 仍返回完整快照；全量解析、排序和传输没有因此消失。Core 汇总/分页/增量接口、Flow 历史关联和价格草稿按模型增量重算不属于本补丁。

## 时间名称

界面使用“上游首包（TTFB）”“首文本（含推理）”“首推理文本”“首回答文本”。兼容字段 `ttfb_ms`、`ttft_ms`、`ttfa_ms`、`timing_version` 均不变。

提示区分上游尝试计时与 UsageReporter 总耗时，明确文本在上游翻译和客户端交付之前被观测；缺失不是零，也不是“模型没有推理”。输出 TPS 标为估算，不称为精确模型解码速度。四种现有语言同步更新。

## 价格 smoke

当前源码包的 V2 种子并非报告中所说的旧 Sol 四项价格：Sol 为 `4 / 0.4 / Auto / 20`，GPT-5.4 才是该场景唯一匹配当前预设的项。V2 行为保留。

V3 正向恢复场景之前仍使用 Sol 旧价 `5 / 0.5 / 6.25 / 30`；现改为当前包内目录价 `4 / 0.4 / 5 / 20`。旧价另设负向场景，确认仍被保留为自定义覆盖，而不是被自动移除。

`scripts/fixtures/usage-pricing-smoke.json` 同时供 Python 浏览器 smoke 和 Node 测试读取。浏览器启动前运行实际价格引擎测试，目录与播种数据再次不一致时先报告具体场景，而不是等待不可出现的提示超时。Claude 的 `$5 / $0.5 / $6.25 / $25` 断言不改。
