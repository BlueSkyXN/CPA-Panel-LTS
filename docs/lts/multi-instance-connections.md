# 多实例连接 V1

顶部实例选择器不依赖登录状态。连接档案在同一 Panel origin 下共享，每个标签页独立选择实例；活动会话不会随其他标签页切换。名称和环境标签用于区分操作对象，不代表服务端证明的唯一身份。

## 使用与边界

- 添加连接后可保存档案，或直接连接。每条档案单独选择是否记住管理密钥；清空密钥并保存可忘记密钥。
- 退出当前连接不删除档案。删除档案不会终止其他标签页已建立的连接。
- 切换前处理未保存编辑及 OAuth 流程，正在提交的 Management API 写请求须先完成。
- 使用独立临时客户端验证目标的 `/config`。失败保留当前实例和草稿，目标 401 不影响当前认证。
- 验证成功后整页重载，不热替换旧文档的 API client。旧页面叠层、store、弹窗和轮询随文档销毁；通用功能路径保留，资源详情回到列表，不携带旧筛选或资源 ID。
- 非记住密钥在交接时通过 `sessionStorage` 临时传递，30 秒有效，新页面启动即消费删除；正常会话持久化不保存它。记住密钥使用原有可逆混淆，不是加密或安全边界。
- 旧单连接记录成功迁移为档案后移除重复的旧认证存储。回退旧 Panel 不会自动读取新档案，需重新登录；本版本不导出密钥。
- Usage、插件能力、配置等在目标会话重新加载。本地价格表仍全局共享。不提供跨实例聚合、批量修改或后台全实例轮询。

## 部署前提

使用固定 Panel 地址，并验证浏览器可访问各 Core。跨域请求须显式允许 `Authorization`（不能仅依赖 `Access-Control-Allow-Headers: *`），还须正确暴露版本及 capability 响应头。远程管理开关、网络可达性和 HTTPS/HTTP 混合内容由实际部署决定。

本功能不修改 Core、反向代理或线上配置。Probe 成功不等于已验证所有目标功能：新会话仍重新认证及检测能力，网络或配置在交接间变化时会显示连接失败，但实例选择器保持可用。

## 验证

- `npm run test:connections`：旧存储迁移、凭据保存选择、一次性交接、双标签页选择隔离、损坏值和路径恢复。
- `npm run smoke:connections`：两个独立的本地 mock Core，真实跨域 Authorization、失败保留、A→B→A、双标签页、未保存配置及移动端布局。
- `npm run validate:lts`、`npm run smoke:lts`：现有 LTS 功能回归。

Mock smoke 不证明实际部署 CORS、Core compatibility 或发布状态。交接不能撤销已经到达服务端的写操作。
